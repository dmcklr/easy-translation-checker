Translation Checker

Drop a JSON file here or open one via ☰ › Import.

Format: [{"ID": 123, "ItemKey": "...", "Text": "...", "Translation": "..."}]

Instructions

How it works

  1. Import: Open the menu (☰) and click Import. Choose your JSON file. You can also drag the file onto the page.
  2. Check: On the left you see the item key, its ID and the English text. On the right you see the translation. If it is wrong, just type the correct text. Changed texts are marked yellow.
  3. Mark as done: When a translation is correct, tick the box on the right. The entry disappears. Turn on Show done to see done entries again.
  4. Search: Use the search field to find an item key, an ID or a text.
  5. Export: Click ☰ › Export. This downloads your work as <date>_<time>_<name>_edited.json, including the “done” marks. Import this file later to continue where you stopped.

Good to know

  • Your original file is never changed. Only Export creates a new file.
  • Your progress is saved automatically in this browser on this computer. It stays there until you import a new file – even after an export or when you close the browser.
  • It is lost if you use another browser or PC, private mode, or clear your browser data. Export regularly to be safe.
  • Before a new file replaces the current one, you are asked to export and to confirm.

Clear current translations list?

⚠ When importing a new file, all changes will be removed from this browser. Export your work first if you want to keep it.
